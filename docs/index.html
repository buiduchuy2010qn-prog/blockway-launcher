💬 Câu Hỏi Thường Gặp (FAQ)

Giải đáp nhanh những thắc mắc phổ biến nhất trước khi tải BlockWay Launcher.

Chơi Offline và tài khoản Microsoft có dùng chung được không?

Được. Bạn có thể chuyển đổi tức thì giữa Offline (tên nhân vật local), Microsoft và Cloud 24/7 (OTP email) ngay trên Trang chủ mà không mất Map hay Mod. Cần bản quyền Minecraft: Java Edition để vào máy chủ chính thức.

Nhân BlockWay Rust mở <1s và Kho Mod Đã Cài hoạt động ra sao?

Ở cột Kính Mờ bên trái, bạn có thể chuyển 1 chạm giữa 🦀 BlockWay Rust (mở ấm <1s bằng Rust Vulkan/DX12 kèm gói .hmod) và 7 Core Java. Mọi Mod/Shader đã cài luôn tự xếp lên đầu danh sách (✓ Đã Cài) để dễ quản lý.

Nên tải bản Setup (.EXE) hay bản Portable (.EXE)?

Dùng trên máy tính cá nhân hãy chọn Setup (.EXE) để có sẵn biểu tượng Desktop và cập nhật OTA. Nếu ngồi ngoài quán Net hoặc chạy từ USB, chọn Portable (.EXE) để mở lên chơi ngay không cần cài đặt.

Linux tải AppImage hay .DEB? Steam Deck / Ubuntu chạy được không?

Cả hai bản đều hỗ trợ x86_64 (không có ARM). AppImage dùng cho Arch, Fedora, SteamOS (chạy chmod +x; Ubuntu 22.04+ / Steam Deck cần libfuse2). .DEB dùng cho Ubuntu/Debian/Mint via sudo apt install.

Làm sao đóng gói bộ Mod của mình gửi bạn bè qua Zalo / Discord?

Mở mục 🧩 Kho Mod → nhấn 📦 Đóng gói gửi bạn. Launcher xuất ra đúng 1 tệp .mrpack siêu nhẹ chứa danh sách Mod, Shader và Config đã chọn — bạn bè chỉ cần kéo-thả vào cửa sổ BlockWay là tự tải khớp 100%.

Chuyển Map/Mod từ TLauncher cũ sang và hỗ trợ những bản Minecraft nào?

Chỉ mất 1 cú nhấp với Đồng bộ từ Launcher cũ (TLauncher, Official, CurseForge, Prism, Modrinth). BlockWay hỗ trợ trọn dải MC 1.7.10 → 26.3 và tự động chọn đúng Java 8 / 17 / 21 / 25.
