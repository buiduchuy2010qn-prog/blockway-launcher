💬 Câu Hỏi Thường Gặp (FAQ)

Giải đáp nhanh những thắc mắc phổ biến nhất khi mới tải và sử dụng BlockWay Launcher.

Chơi Offline (tên nhân vật local) và tài khoản Microsoft dùng chung được không?

Được. Bạn có thể chuyển đổi tức thì giữa Offline / tên nhân vật local, tài khoản Microsoft và Cloud 24/7 (OTP email) ngay tại Trang chủ mà không mất Map hay Mod. Cần bản quyền Minecraft: Java Edition để chơi online trên máy chủ chính thức.

Nhân BlockWay Rust (Horizon) và Kho Mod đã cài hoạt động như thế nào?

Ở cột Kính Mờ bên trái, bạn có thể chuyển 1 chạm giữa 🦀 BlockWay Rust (chạy trực tiếp bằng Rust Vulkan/DX12 với Shader WGSL & gói .hmod) và 7 Core Java. Khi mở Kho Mod, mọi Mod/Shader/Resource Pack bạn đã cài luôn tự động xếp liên tục ở đầu danh sách (✓ Đã Cài) để dễ quản lý ngay cả khi đã cài hơn 30–50 Mod.

Nên tải bản Setup (.exe) hay bản Portable (.exe)?

Nếu dùng trên máy tính cá nhân ở nhà, bạn nên chọn Bản Cài Đặt Chuẩn (Setup .exe) để có sẵn biểu tượng ngoài màn hình Desktop. Nếu ngồi ngoài quán Net hoặc chép vào USB, hãy chọn Bản Portable .exe để bấm đúp mở lên chơi ngay không cần cài đặt!

Linux tải AppImage hay .DEB? Steam Deck / Ubuntu chạy được không?

Cả hai đều x86_64 (không có ARM). AppImage cho Arch, Fedora, SteamOS, USB: tải về, chmod +x BlockWay.Launcher-Linux-*.AppImage rồi chạy. Ubuntu 22.04+ và Steam Deck nếu mở không lên thì cài libfuse2. .DEB cho Ubuntu / Debian / Mint: sudo apt install ./BlockWay.Launcher-Linux-*.deb. OTA in-app tự thay AppImage; bản .deb cài /opt thì tải bản mới về thư mục Tải xuống.

Làm sao đóng gói bộ Mod của mình để gửi cho bạn bè cùng chơi?

Vào mục 🧩 Kho Mod (hoặc dòng gói Modpack đã cài) → bấm 📦 Đóng gói gửi bạn. Launcher sẽ tạo ra 1 tệp .mrpack gọn nhẹ chứa đủ danh sách Mod, Shader và tinh chỉnh của bạn — bạn bè chỉ cần kéo-thả tệp đó vào BlockWay là tự tải khớp 100%!

Chuyển dữ liệu Thế giới (Saves) và Mod từ TLauncher cũ sang có dễ không?

Chỉ mất 1 cú nhấp chuột! Bấm nút Đồng bộ dữ liệu từ Launcher cũ — BlockWay sẽ tự quét TLauncher, Official, CurseForge, Prism, Modrinth để chuyển nguyên vẹn Thế giới, Mods, Shaders và danh sách Server sang.

Launcher hỗ trợ những phiên bản Minecraft và Java nào?

Hỗ trợ trọn vẹn từ 1.7.10, 1.8.9, 1.12.2, 1.16.5, 1.20.1, 1.21.4, 1.21.11 cho tới 26.2 & 26.3 cùng đủ 8 Core (BlockWay Rust, Vanilla, OptiFine, Fabric, Forge, NeoForge, Quilt, Legacy Fabric) và tự tải đúng chuẩn Java 8 / 17 / 21 / 25.
